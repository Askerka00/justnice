# Инструкции для агента Antigravity (ConveerSites)

Этот файл содержит правила автоматизации и быстрые команды (шорткаты), которые пользователь может отправлять без длинных описаний контекста.

---

## ⚡ Быстрые команды (Шорткаты)

### 1. `/logo [Название компании] [Описание/Текст]`
Используется, когда нужно сгенерировать логотип для компании, зафиксировать его и создать под неё полноценный демонстрационный сайт.
**План действий для агента:**
1. Сгенерировать квадратный векторный или минималистичный логотип с помощью инструмента `generate_image` и сохранить его в папку проекта `public/img/logos/` с нормализованным названием (например, `atlant-metall-logo.png`).
2. Найти эту компанию в файле [sales_tracker.csv](file:///Users/aibolat/Projects/ConveerSites/sales_tracker.csv) и записать путь к логотипу в колонку «Заметки».
3. Подобрать нужные блоки, структуру и составить полноценную качественную JSON-конфигурацию сайта по гайду [conveer_site_builder_guide.md](file:///Users/aibolat/Projects/ConveerSites/conveer_site_builder_guide.md). Сохранить этот JSON-файл в папку `server/assets/data/` (например, `atlant-metall.json`).
4. Показать пользователю сгенерированный логотип, подтвердить создание сайта и прислать краткое резюме структуры сайта.

---

### 2. `/redesign [Ссылка на старый сайт]`
Используется для парсинга старого сайта клиента и создания его красивой версии на ConveerSites.
**План действий для агента:**
1. Прочитать содержимое старого сайта по ссылке с помощью `read_url_content`.
2. Извлечь оттуда ключевую информацию: контакты, преимущества, список услуг, тексты.
3. На основе извлеченных данных составить современную JSON-структуру сайта по гайду [conveer_site_builder_guide.md](file:///Users/aibolat/Projects/ConveerSites/conveer_site_builder_guide.md).
4. Сохранить новый JSON-файл в папку `server/assets/data/` (например, `new-atlant.json`).
5. Написать пользователю краткий отчет: что было на старом сайте ➡️ что улучшено в новом дизайне.

---

### 3. `/contact [Название компании] - [Результат]`
Используется для быстрого обновления статуса в таблице продаж.
**План действий для агента:**
1. Найти компанию в [sales_tracker.csv](file:///Users/aibolat/Projects/ConveerSites/sales_tracker.csv).
2. Записать дату контакта в колонку «Дата Msg1» (если это первый контакт) или обновить даты Msg3/Msg4.
3. Обновить колонку «Ответ клиента» текстом результата.
4. Автоматически определить и обновить статус (`Интерес`, `Отказ`, `Игнор`, `Оплата`).
5. Перезаписать CSV-файл и подтвердить обновление пользователю.

## 🛠️ Дополнительные правила поведения
- Всегда сохраняй контекст того, что проект ConveerSites — это билдер сайтов для локального бизнеса в Казахстане.
- Работай молча и быстро по этим командам, не переспрашивай лишних деталей.
- Если отправлена просто ссылка без команды, по умолчанию воспринимай это как запрос `/redesign [Ссылка]`.
- Если отправлен скриншот логотипа или запрос текста, по умолчанию воспринимай это как `/logo`.
